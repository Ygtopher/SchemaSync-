# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-14
### Added
- Multi-database support: PostgreSQL, MS Access (.accdb/.mdb), embedded H2 engine.
- Table browsing, column selection, dynamic WHERE clause builder.
- Visual Join Builder for building queries without manual SQL.
- Script Builder with native PostgreSQL meta-command emulation (\\set, \\gset, \\echo).
- Schema and Data diff engine with side-by-side visualization.
- Exporting to CSV, Excel (.xlsx), and raw SQL INSERTs.
- FlatLaf Dark Mode and Light Mode with instant toggle.
