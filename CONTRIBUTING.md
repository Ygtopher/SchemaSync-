# Contributing to SchemaSync

We welcome contributions from the community!

## Development Setup
1. Clone the repository.
2. Ensure JDK 11+ and Maven 3.8+ are installed.
3. Run `mvn clean test` to execute unit tests.
4. Run `mvn clean package` to build the standalone shaded JAR.

## Code Standards
- Java 11 compliant.
- Follow Google Java Style guidelines.
- Add unit tests for all new dialects, parsers, and comparators.
