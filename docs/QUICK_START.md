# SchemaSync Quick Start

1. Start SchemaSync: `java -jar target/access-db-tool-1.0-SNAPSHOT-shaded.jar`
2. Select your database file (.accdb, .sql, or .sql.gz) or connect to PostgreSQL.
3. Switch to **Table Compare** tab to diff tables.
4. Switch to **Script Builder** tab to execute multi-step SQL scripts with \\set and \\gset.
